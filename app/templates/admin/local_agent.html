What This Is

A browser page can't talk to a USB-connected programmer or poll a smart plug on the workshop LAN directly. The Local Agent is a small helper program (local_agent/flasher_agent.py) that runs on the workshop PC instead — the one with the boards and plugs physically attached to it — and listens on http://localhost:8765. Firmware Flashing (Kit Firmware Versions and Build detail) and IoT Power Monitoring (Assets) both talk to it from right inside this app: the page in your browser calls the agent on localhost, the agent does the real USB/network work, and it reports results back here using the API key below.

Workshop PC Setup

On the PC with the USB programmer / on the workshop LAN:

  1. Copy the local_agent/ folder from the app package onto that PC.
  2. Edit local_agent/config.json: set mintmotive_url to {{ request.host_url.rstrip('/') }} and api_key to the key above.
  3. Install its dependencies (pip install -r local_agent/requirements.txt) — this includes pyserial for USB and avrdude must be on the system PATH for AVR flashing.
  4. Run python3 local_agent/flasher_agent.py. It listens on http://localhost:8765 and only accepts connections from that same machine's browser.
  5. Open Kit Firmware Versions or a Build's detail page in this app, on that same PC — the "Flash to Device" button will now find the agent automatically.
